Inside the production planner

The planning system is designed as four stages, from messy project data to a schedule people can act on.

Inputs

  • Projects and tasks
  • Task dependencies
  • Employee skills
  • Working hours

Constraints

  • Precedence between tasks
  • Skill-to-task matching
  • Personnel availability
  • Material and resource limits

Solver

  • CP-SAT constraint model
  • Schedule and assignment search
  • Python-based implementation

Outputs

  • Task timing and assignees
  • Raw material requirements
  • Progress and delivery tracking
  • Automated notifications
